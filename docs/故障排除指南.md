## 🔍 常见问题诊断

### 1. 登录问题

#### 症状：用户名密码正确但无法登录
**可能原因**：
- 数据库连接问题
- 权限系统故障
- 用户账户被锁定

**诊断步骤**：
```python
# 检查用户表
python -c "
import sqlite3
conn = sqlite3.connect('qr_system.db')
cursor = conn.cursor()
cursor.execute('SELECT username, is_active FROM users')
print(cursor.fetchall())
conn.close()
"
```

**解决方案**：
1. 重置用户密码
2. 检查用户状态
3. 重建权限缓存

#### 症状：登录后立即闪退
**诊断工具**：
```bash
python PRECISE_DEBUG.py
```

**查看日志**：
```bash
tail -f logs/qr_system_$(date +%Y%m%d).log
```

### 2. 模块加载失败

#### 症状：某个功能模块无法打开
**检查方法**：
```python
# 测试模块导入
python -c "
from modules.qr_print_widget import QRPrintWidget
print('QR打印模块 OK')
"
```

**常见错误**：
- 依赖库缺失
- 权限不足
- 配置文件错误

**解决步骤**：
1. 检查模块文件完整性
2. 验证用户权限
3. 重装相关依赖

### 3. 二维码生成问题

#### 症状：二维码生成失败或显示空白
**诊断命令**：
```python
# 测试二维码库
python -c "
import qrcode
qr = qrcode.QRCode()
qr.add_data('测试')
qr.make()
print('二维码库正常')
"
```

**检查要点**：
- 二维码内容长度
- 字符编码问题
- 图片生成路径权限

### 4. 自动同步故障

#### 症状：JSON文件不自动上传
**检查同步状态**：
```powershell
# 查看同步进程
Get-Process | Where-Object {$_.ProcessName -eq "powershell" -and $_.CommandLine -like "*fixed_auto_sync*"}

# 检查任务计划
Get-ScheduledTask | Where-Object {$_.TaskName -like "*同步*"}

# 查看同步日志
Get-Content "auto_sync\logs\fixed_sync.log" -Tail 20
```

**网络连接测试**：
```bash
# 测试FTP连接
telnet scan.example.com 21

# 检查DNS解析
nslookup scan.example.com
```

**重启同步服务**：
```bash
# 停止现有进程
taskkill /f /im powershell.exe /fi "CommandLine eq *fixed_auto_sync*"

# 重新启动
scripts\smart_auto_sync_hidden.bat
```

## 🚑 应急恢复流程

### 完全系统故障
1. **停止所有相关进程**
2. **备份当前状态**
3. **恢复最新可用备份**
4. **验证系统功能**
5. **记录故障原因**

### 数据丢失恢复
1. **立即停止系统操作**
2. **检查自动备份**
3. **恢复数据库文件**
4. **验证数据完整性**
5. **重新启动服务**

### 权限系统故障
1. **使用超级管理员账户**
2. **重置权限数据库**
3. **重新分配用户权限**
4. **测试权限功能**
