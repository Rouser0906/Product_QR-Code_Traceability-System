## 🎯 系统概述

### 系统功能
QR系统是一个企业级二维码管理平台，提供以下核心功能：

- **二维码生成与打印**：支持多种二维码类型和格式
- **公司信息管理**：部门、员工、产品信息管理
- **物流追踪**：物流信息记录和查询
- **权限控制**：基于角色的访问控制
- **自动同步**：JSON文件自动上传到FTP服务器
- **公网扫码**：支持公网访问的扫码功能

### 技术架构
- **前端**：PyQt5 桌面应用
- **后端**：Python + SQLite数据库
- **自动同步**：PowerShell脚本 + 文件监控
- **Web服务**：PHP + HTML公网扫码界面

## 👤 用户操作指南

### 登录系统
1. 双击桌面的QR系统图标
2. 输入用户名和密码
3. 点击"登录"按钮

### 二维码打印操作
1. **选择公司**：从下拉菜单选择目标公司
2. **选择部门**：选择相应的部门
3. **填写信息**：
   - 产品名称
   - 产品规格
   - 生产日期
   - 其他必要信息
4. **预览二维码**：点击"预览"查看二维码效果
5. **打印二维码**：确认无误后点击"打印"

### 数据查询
1. **历史记录**：查看已生成的二维码记录
2. **物流信息**：查询产品物流状态
3. **扫码统计**：查看二维码扫描数据

### 公网扫码
- 使用手机扫描二维码
- 自动跳转到产品信息页面
- 支持多语言显示

## 🔧 管理员操作

### 用户管理
1. **添加用户**：
   ```
   工具 → 用户管理 → 添加用户
   填写：用户名、密码、员工编号、所属部门
   ```

2. **权限分配**：
   ```
   选择用户 → 角色管理 → 分配角色
   可用角色：管理员、操作员、查看者
   ```

3. **用户状态管理**：
   - 启用/禁用用户
   - 重置用户密码
   - 查看用户活动日志

### 系统配置
1. **公司信息维护**：
   ```
   系统设置 → 公司管理
   - 添加/编辑公司信息
   - 设置公司LOGO
   - 配置联系方式
   ```

2. **部门管理**：
   ```
   系统设置 → 部门管理
   - 创建部门层级
   - 分配部门负责人
   - 设置部门权限
   ```

### 数据备份
1. **手动备份**：
   ```
   工具 → 数据备份 → 立即备份
   备份位置：backup文件夹
   ```

2. **自动备份**：
   - 系统每天自动备份
   - 保留最近30天的备份
   - 可在设置中调整备份频率

## 🔄 自动同步系统

### 工作原理
系统监控本地JSON文件变化，自动上传到FTP服务器：

**监控目录**：
- `cloud/demo_json_a/` - A公司JSON文件
- `cloud/demo_json_b/` - B公司JSON文件

**上传目标**：
- FTP服务器：`your-ftp-server.com`（示例，请替换为实际服务器地址）
- 目标目录：`/companies/demo_json_a/` 和 `/companies/demo_json_b/`

### 状态检查
1. **查看同步日志**：
   ```
   位置：auto_sync/logs/fixed_sync.log
   包含：上传记录、错误信息、连接状态
   ```

2. **手动重启同步**：
   ```
   双击：scripts/smart_auto_sync_hidden.bat
   或通过任务管理器重启"QR自动同步_隐藏"任务
   ```

### 故障排除
- **文件未上传**：检查网络连接和FTP权限
- **同步服务停止**：查看Windows任务计划程序
- **日志文件过大**：定期清理旧日志文件

## ❓ 常见问题

### Q1: 系统启动失败怎么办？
**A**: 按以下步骤排查：
1. 运行诊断工具：`python CRASH_DETECTIVE.py`
2. 检查数据库文件是否存在：`qr_system.db`
3. 确认Python环境：`python --version`
4. 重装依赖：`pip install -r requirements.txt`

### Q2: 二维码打印空白
**A**: 检查以下项目：
1. 打印机驱动是否正常
2. 二维码内容是否过长
3. 打印设置是否正确
4. 查看系统日志错误信息

### Q3: 自动同步不工作
**A**: 故障排除步骤：
1. 检查网络连接：`ping your-ftp-server.com`（请替换为您的实际服务器地址）
2. 查看同步日志：`auto_sync/logs/fixed_sync.log`
3. 重启同步服务：运行 `scripts/smart_auto_sync_hidden.bat`
4. 验证FTP账户：用户名 `your_ftp_username`

### Q4: 忘记登录密码
**A**: 管理员重置步骤：
1. 使用超级管理员账户登录
2. 进入用户管理界面
3. 选择目标用户 → 重置密码
4. 通知用户新密码

### Q5: 数据库损坏
**A**: 恢复方法：
1. 停止系统运行
2. 从backup文件夹恢复最新备份
3. 重命名：`backup_YYYYMMDD.db` → `qr_system.db`
4. 重启系统验证
