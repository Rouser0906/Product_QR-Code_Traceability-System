### 附：FTP 自动同步自检清单
用于重启电脑后快速自检 FTP 自动同步（auto_sync）是否正常：

1) 进程/服务
- [ ] auto_sync 服务已启动（Windows：任务管理器或服务中确认；或查看托盘/日志）

2) 配置核对（auto_sync/config.json）
- [ ] `auto_sync.enabled = true`
- [ ] `file_watcher.enabled = true`
- [ ] 监控目录存在：
  - company_a: `C:\\Projects\\qr-system\\cloud\\company_a\\data`
  - company_b: `C:\\Projects\\qr-system\\cloud\\company_b\\data`
- [ ] 文件匹配规则：
  - company_a: `A-Q*.json`
  - company_b: `B-Q*.json`
- [ ] 注意：当前监控 `recursive=false`，请将测试文件放在 data 目录根下（不要放子目录）

3) 测试方法
- 将两个示例文件放入对应目录（或自行复制一份并改名）：
  - `A-Q_TEST_AUTO_SYNC.json` → 放入 company_a 的 data 目录
  - `B-Q_TEST_AUTO_SYNC.json` → 放入 company_b 的 data 目录
- 预期：日志出现“检测到新JSON文件”、加入事件队列并上传成功；远端目录 `/company_a/data/`、`/company_b/data/` 出现对应文件

4) 日志与排错
- [ ] 查看 `logs/auto_sync.log` 是否有错误（认证失败、网络不通、超时、权限不足等）
- [ ] 若仅其中一个任务失败，检查远端路径权限与 FTP 账号
- [ ] 若落在“已存在”判断，可能是远端已有同名文件（当前允许覆盖）

5) 其他注意
- 写入完成判定：程序会等待文件大小稳定（最多 ~5 秒），请避免用超大文件做首测
- 文件名大小写需符合匹配规则（Windows 不敏感，建议保持大写前缀）
