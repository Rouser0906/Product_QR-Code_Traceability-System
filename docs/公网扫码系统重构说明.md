# 公网扫码系统重构说明（变更清单 / 回滚策略 / 运维指引）

本文档用于对本次“产品溯源二维码发行＆管理系统（公网扫码秒开）”重构进行归档，便于团队协作、运维交接与后续变更。

## 1. 目标与范围
- 全球移动端扫码无感秒开，展示二维码 JSON 中全部信息。
- 统一新旧二维码 URL 指向，彻底移除历史硬编码路径/域名。
- 保留策略：云端 *.json 文件保存 3 周年，超期自动清理。
- 打包为绿色便携版（后续），各电脑部署不影响 FTP 自动同步。

## 2. 关键变更清单
- URL 统一：二维码指向 https://your-company-domain.com/index.html?code={QR_CODE}
- 本地 JSON 目录统一：
  - A：cloud/demo_json_a
  - B：cloud/demo_json_b
- 云端目录统一：
  - /companies/demo_json_a/
  - /companies/demo_json_b/
- API（api/get_product_data.php）：先本地 cloud/{demo_json_a|demo_json_b}，后远端 https://your-company-domain.com/companies/{demo_json_a|demo_json_b}/{code}.json，含缓存与性能日志。
- 同步与容错：auto_sync/* 增强（FTPS 回退 FTP、断线重试、存在性检查）。
- 3 年清理：新增脚本 scripts/server_cleanup_3years.ps1 + 计划任务注册脚本 scripts/register_cleanup_3years_task.ps1。
- 清理豁免：0*.bat 与 shared.md / share.md 永久保留。

## 3. 部署步骤（服务器端）
1) 复制清理脚本
- 将仓库内 scripts/server_cleanup_3years.ps1 上传至服务器：
  - 推荐路径：C:\inetpub\wwwroot\companies\scripts\server_cleanup_3years.ps1
2) 注册计划任务（管理员 PowerShell）
```
PowerShell -NoProfile -ExecutionPolicy Bypass -File C:\path\to\register_cleanup_3years_task.ps1 -ScriptPath "C:\inetpub\wwwroot\companies\scripts\server_cleanup_3years.ps1" -TaskName QR_Cleanup_3Years -StartTime 03:00
```
3) IIS URL Rewrite（兼容旧码）
- 将 web.config.sample 的 <system.webServer> 段复制到站点根目录 web.config，或合并规则。
- 重启 IIS：
```
iisreset
```

## 4. 部署步骤（应用端，绿色便携准备）
- auto_sync/config.json 的 local_path 支持 ${APP_ROOT} 占位符：
```
{
  "sync_tasks": [
    {
      "task_id": "a_sync",
      "company": "a",
      "local_path": "${APP_ROOT}\\cloud\\demo_json_a\\",
      "remote_path": "/companies/demo_json_a/",
      "file_pattern": "A-Q*.json",
      "enabled": true
    },
    {
      "task_id": "b_sync",
      "company": "b",
      "local_path": "${APP_ROOT}\\cloud\\demo_json_b\\",
      "remote_path": "/companies/demo_json_b/",
      "file_pattern": "B-Q*.json",
      "enabled": true
    }
  ]
}
```
- auto_sync/auto_sync_service.py 会解析 ${APP_ROOT} 并回退到相对目录。

## 5. 验证清单（回归用）
- 二维码生成：打印面板生成的二维码链接统一为 https://your-company-domain.com/index.html?code=...
- JSON 上传：新生成 JSON 能自动上传至 /companies/{demo_json_a|demo_json_b}/。
- 旧码兼容：历史扫码能 301 至新域名（需完成 URL Rewrite）。
- API 性能：同域 API /api/get_product_data.php 正常返回；cache 命中率提升。
- 清理任务：计划任务日志 _logs/cleanup_YYYYMMDD.log 正常生成。

## 6. 回滚策略
- URL 指向回滚：将二维码生成逻辑改回 scan.example.com（不推荐）。
- 目录回滚：将 cloud/demo_json_a -> cloud/company_a/data；cloud/demo_json_b -> cloud/company_b/data。
- 清理任务回滚：Unregister-ScheduledTask -TaskName QR_Cleanup_3Years -Confirm:$false。

## 7. 维护建议
- 尽快启用 FTPS 并为 FTP 用户设置最小权限目录；定期轮换 FTP 密码。
- 建议启用 CDN/HTTPS/HTTP2；设置合理缓存头和自动刷新策略。
- 配置监控告警：失败上传、API 异常、计划任务失败应推送到企业 IM。
