# Security Policy

## Reporting a Vulnerability
Please report security issues privately so we can address them promptly:

- Use GitHub Security Advisories: https://github.com/Rouser0906/Product_QR-Code_Traceability-System/security/advisories/new
- Do NOT open a public issue for security vulnerabilities

We will acknowledge receipt within 3 business days and aim to provide a fix or remediation plan within 14 business days, depending on severity.

## Supported Versions
We aim to support the latest main branch and the most recent tagged release.

## Best Practices for Deployers
- Always change default credentials immediately (see README)
- Keep dependencies up to date
- Store secrets outside the repo (env vars or configuration files excluded by .gitignore)
- Enable HTTPS in production and restrict database/network access
